# 🍽️ NutriLens Frontend

NutriLens is an AI-powered meal analysis web application that helps users understand the nutritional value of their meals. Users can upload a meal image and receive AI-generated nutrition estimates, a health score, personalized health tips, and healthier food alternatives.

This repository contains the frontend of the NutriLens application, built with React and Tailwind CSS.

---

## ✨ Features

- Upload meal images
- Supports JPG, JPEG, PNG, and WEBP images
- AI-powered meal analysis
- Displays estimated calories
- Shows protein, carbohydrates, and fat content
- Displays an overall health score
- Provides AI-generated coach tips
- Suggests healthier food alternatives
- Shows fitness goals under **Best For**
- Responsive design for mobile and desktop
- Loading and error handling
- Easy navigation between upload and result pages

---

## 🛠️ Tech Stack

- React
- Vite
- Tailwind CSS
- React Router DOM
- Axios
- Lucide React
